# Security

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/kemalcalak/design-editor/security/advisories/new), not in public issues. Include the version, the platform and the steps to reproduce.

Design Editor runs locally: the MCP server listens on `127.0.0.1` only, and keys you enter stay on your machine.

More: [code signing policy](./docs/security/code-signing-policy.md) · [antivirus false positives](./docs/security/antivirus-false-positives.md)
