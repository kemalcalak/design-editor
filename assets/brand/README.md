# Design Editor brand

The mark is a solid "D": the stem and top bar are the person (`#3E6DF5`), the curve that starts at an anchor dot is the agent (`#8FA8FA`), and the `>_` prompt inside is the agent's command line. Background `#141519`.

| File | Use |
|---|---|
| `design-editor-icon-dark.svg` | App icon, full-bleed rounded square (Windows, Chrome extension) |
| `design-editor-app-icon-macos.svg` | macOS app icon on the 1024 grid with transparent margin |
| `design-editor-icon-light.svg` | App icon on white |
| `design-editor-symbol.svg` | Symbol only, transparent |
| `design-editor-symbol-mono.svg` | One-color symbol |

Regenerate the PNG / ICNS / ICO files after editing an SVG:

```bash
scripts/generate-icons.sh
```
